# CampusPe Landing Page

A responsive CampusPe landing page built with Next.js, React, TypeScript, and CSS.
<br>
live demo : https://campuspe-landing-liart.vercel.app/
## Run it on your computer

1. Install Node.js (LTS) from [nodejs.org](https://nodejs.org/).
2. Open a terminal in this folder.
3. In Windows PowerShell, run `npm.cmd install` once to download the project dependencies. (`npm.cmd` avoids PowerShell's script execution policy blocking `npm.ps1`.)
4. Run `npm.cmd run dev` and open `http://localhost:3000` in your browser.

To make a production build, run `npm.cmd run build`. To serve that build locally, run `npm.cmd run start`.

## Publish it

Push this folder to a new GitHub repository, then import that repository into Vercel. Vercel detects Next.js automatically and provides a live website URL after deployment. Add the GitHub repository and deployed URL to your assignment submission.

## Design note

The page follows the supplied CampusPe screenshots and uses CSS illustrations for the product screens and dashboard cards. Update the sample contact details and replace the partner wordmarks with official assets if you have them.
